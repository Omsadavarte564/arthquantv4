# ArthQuant — Complete Engineering & Quantitative Project Audit (`PROJECT_AUDIT.md`)

**Audit Date:** 2026-11-20 IST  
**Repository:** `/app/applet` (Full-Stack TypeScript + Express + Vite + React 19)  
**Scope:** End-to-end codebase inspection across frontend, Express API, quantitative engine, ML walk-forward pipeline, data layer, paper-trading ledger, risk engine, RAG, and MCP server.

---

## 1. Architecture & Information Flow Summary

- **Backend Entry (`server.ts`, 915 lines):** Express server on port `3000` hosting REST endpoints (`/api/*`), Streamable HTTP MCP (`/mcp`), and Vite dev/static SPA middleware.
- **Market Data Layer:**
  - `server/data/nseUniverse.ts` — 24 NSE large/mid-cap equities + 3 indices (`NIFTY50`, `BANKNIFTY`, `SENSEX`), deterministic 14-session intraday OHLCV generator (`1m`, `5m`, `15m`; `1,050` `5m` bars per symbol), NSE 2026 holiday calendar, IST session clock.
  - `server/data/nseDirectory.ts` — Syncs & caches NSE Cash Equity master CSV from `https://api.kite.trade/instruments/NSE` (`3,108+` instruments) with batch public quotes.
  - `server/data/publicMarketFeed.ts` — Fetches Yahoo Finance `.NS` public chart (`1m`/`5m`/`15m`) & spark batch quotes.
  - `server/data/validator.ts` — Deduplicates timestamps, filters malformed OHLC, checks session gaps and `>10%` price jumps, and enforces live freshness when requested.
- **Quantitative & ML Pipeline:**
  - `server/quant/indicators.ts` — Causal EMA(9/12/21/26), SMA(50), MACD, Session VWAP, ORB-15, Bollinger(20,2), Relative Volume, Wilder RSI(14), ATR(14), ADX(14), Supertrend(14,2.8), 20-bar Support/Resistance.
  - `server/quant/regime.ts` — Rule-based 5-regime classifier (`STRONG_TREND_BULL`, `STRONG_TREND_BEAR`, `SIDEWAYS_RANGE`, `HIGH_VOL_BREAKOUT`, `UNCERTAIN_CHOP`).
  - `server/quant/mlEngine.ts` — 8-feature L2-regularized Logistic Regression + Platt scaling (`ArthQuant-LogitPlatt-v1.4`).
  - `server/quant/strategies.ts` — 15 built-in strategies + custom no-code visual rule builder.
  - `server/quant/backtester.ts` — Next-bar open execution backtester with conservative intrabar SL-before-Target resolution and NSE statutory fee deduction (`server/quant/costs.ts`).
  - `server/quant/signals.ts` — Generates live scanner snapshot, signals, indices, sector rotation, and `DataHealthStatus`.
  - `server/quant/riskEngine.ts` — Independent 9-rule pre-trade gatekeeper and deterministic position sizer.
- **Persistence & Execution (`server/storage/stateStore.ts`, `server/brokers/brokerAdapter.ts`):**
  - Atomic JSON persistence (`data/arthquant-state.json`) for watchlist, custom strategies, risk config, audit log, paper account (`₹10,00,000` virtual), and backtest history.
  - All 4 broker adapters (`zerodha`, `upstox`, `dhan`, `angelone`) keep `liveExecutionEnabled: false` (`liveTradingLocked: true`).
- **AI Copilot, RAG & MCP (`server/ai/*`, `server/rag/*`, `server/mcp/*`):**
  - 20-tool MCP server (`/mcp`, Bearer auth + 60 req/min rate limit + audit log), 5-collection Hybrid BM25/Vector RAG store (`data/rag-knowledge-base.json`), Gemini orchestrator with deterministic grounded fallback when `GEMINI_API_KEY` is unavailable/invalid (`401` in current sandbox).
- **Frontend (`src/App.tsx`, `src/views/*`, `src/components/*`):**
  - 11-tab React + Tailwind + Lightweight Charts + Recharts terminal.

## 2. Prioritized Audit Findings

| # | Severity | Module / Line(s) | Problem Description | Why It Is a Problem & Financial Impact | Recommended Solution | Verification / Test Plan |
|---|---|---|---|---|---|---|
| 1 | **Critical** | `server/quant/mlEngine.ts` (L74, L182–188) | **Label-Horizon Embargo Leakage:** `buildLabeledDataset` uses a `horizon = 10` bar forward triple barrier (`i+1 .. i+10`), yet `embargo = Math.min(6, Math.max(1, Math.floor(total * 0.03)))` caps the gap at **6 bars**. | The last 4 bars of `trainSet` evaluate forward labels overlapping `valSet`, and the last 4 bars of `valSet` overlap `testSet`. Optimistically biases Platt calibration and OOS test metrics. | Enforce `embargo >= horizon` (minimum `horizon + 1 = 11` bars) AND explicitly purge any sample whose `[entryIndex, maxLabelBar]` interval crosses a split boundary. | Unit test verifying `maxLabelIndex(train) < minFeatureIndex(val)` and `maxLabelIndex(val) < minFeatureIndex(test)`. |
| 2 | **Critical** | `server/quant/backtester.ts` (L37–212) | **Cross-Symbol Sequential Equity Time-Travel:** `runBacktest` loops `for (const rawSym of config.symbols)` running all 14 days for Symbol 1, then starts Symbol 2 on Day 1 with Symbol 1's Day-14 equity. | Equity curve goes backward in time across symbols; portfolio exposure and `maxOpenPositions` are ignored across stocks; Sharpe, Sortino, MaxDD, and compounding are distorted. | Implement a synchronized chronological timestamp-ordered portfolio event loop across all symbols, respecting concurrent `maxOpenPositions`, capital margin caps, and single chronological equity curve. | Test multi-symbol backtest asserting monotonically non-decreasing `equityCurve` timestamps and concurrent open position count `<= maxOpenPositions`. |
| 3 | **High** | `server/quant/backtester.ts` (L44–47) | **In-Sample Backtest Leakage When `useOutOfSampleOnly === false`:** Backtest trains weights & Platt scaler on 76% of the dataset (`0..valEnd`), then trades starting at `bar 30` directly over training bars. | On `high-conviction-ai-ensemble`, toggling `OOS=false` inflates simulated Net P&L from `+₹82,311` (`72.53%`) to `+₹677,715` (`76.71%`) — pure lookahead/in-sample memorization. | Replace full-series training when `!useOutOfSampleOnly` with expanding/rolling walk-forward retraining inside the backtest loop (or lock ML evaluation strictly to OOS folds so bar `i` only uses a model trained strictly on `< i - horizon`). | Automated test verifying mutation of bars `> t` cannot alter trades or signals at bar `<= t`. |
| 4 | **High** | `server/quant/mlEngine.ts` (L199–277), `signals.ts` (L87), `strategies.ts` (L518) | **Asymmetric `1 - P(Up)` Short Probability Overstatement:** Only `labelUp` is trained/calibrated, while `probDown` is computed as `1 - probUp`. | Because `labelUp=0` includes `bothZero` neutral/timeout bars (**22.2%** in research data, **35–50%** in real NSE data), `1 - P(Up)` overstates `P(Down)` by **+17.16 percentage points** on average (`STRONG_TREND_BEAR` PF drops to `1.09` vs `3.10` in Bull). | Train dual independent calibrated logistic+Platt estimators: `modelUp` on `labelUp` and `modelDown` on `labelDown`, plus compute `P(Neutral) = max(0, 1 - P(Up) - P(Down))` normalized cleanly. | Assert calibrated `P(Down)` Brier score, ECE, and directional separation match `labelDown` distribution without systematic `+17%` bias. |
| 5 | **High** | `server/quant/mlEngine.ts` (L253–345) | **Incomplete Model Validation & No Baseline / Multi-Fold Regimes:** Missing Accuracy, Precision, Recall, F1, Balanced Accuracy, Confusion Matrix, ECE, Multi-Fold Rolling Walk-Forward, and simple baselines; real `.NS` test showed `AUC 0.44–0.55` & `Brier 0.22–0.28`. | Single split hides calibration drift (`ECE 6.41%`) and obscures when the ML model underperforms trivial rules (e.g. `aboveVwap` baseline = `63.90%` vs model `67.89%` on research data, and fails on real `.NS` data). | Add full classification suite, Confusion Matrix, ECE/MCE, 4 baseline comparisons (Majority, Prev-Candle, VWAP Momentum, EMA Cross), multi-fold rolling walk-forward across market regimes, AND real `.NS` historical validation mode. | Verify all new metrics match deterministic synthetic & real fixtures in `tests/quant.test.ts`. |
| 6 | **High** | Cross-System (`stateStore.ts`, `signals.ts`, `server.ts`) | **No Continuous Prediction Ledger, Outcome Tracking, or Drift Monitor:** System generates signals without recording immutable predictions or resolving outcomes `horizon` bars later. | Cannot verify whether live/paper model calibration holds over time, detect feature/accuracy drift, compare live paper vs backtest variance, or roll back degraded model versions. | Build `server/quant/monitoringEngine.ts` with immutable `PredictionRecord` ledger, automated outcome resolution, rolling ECE/hit-rate drift alerts, feature PSI/z-shift, model version history/rollback, and daily summary UI. | Integration test verifying prediction logging -> bar stepping -> automatic outcome resolution -> drift alert & rollback. |
| 7 | **Medium** | `server/quant/backtester.ts` (L119–180) | **Execution Friction Optimism & Missing Cost Sensitivity / Benchmark:** `slippageBps` is only deducted as cash fee (`charges.slippageCost`), not adverse entry/exit fill slippage; no spread, no liquidity cap (`% of bar volume`), no Gross vs Net, no Buy-and-Hold benchmark, no symbol breakdown. | Underestimates real market impact on higher-turnover strategies (e.g. `price-action-hh-hl` pays `₹2,75,273` fees on `+₹17,268` net). Missing cost sensitivity at `0/5/15 bps`. | Model adverse fill price slippage + spread on entry/exit (without double-counting in `charges`), enforce bar liquidity participation cap, add Gross vs Net, `0/5/15 bps` cost sensitivity table, per-symbol attribution, and benchmark comparison. | Test that higher `slippageBps` degrades fill prices symmetrically and reduces net P&L monotonically; test sensitivity table sums match. |
| 8 | **Medium** | `server/data/validator.ts` (L20–101), `publicMarketFeed.ts` (L74–147) | **Incomplete Data Quality Validation:** `validator.ts` does not flag zero-volume bars during regular NSE hours (`09:15–15:25`), abnormal OHLC wick/body spikes, overnight split/corporate-action gaps (`>15%`), or forming (incomplete) final candles on live `.NS` streams; does not emit `latestSourceTimestampIst` on `TradingSignal`. | Forming candles cause signal flicker mid-bar; corporate action splits create fake volatility/ATR spikes; signals lack explicit market-data source timestamp provenance. | Upgrade `validateCandles` with zero-volume anomaly count, overnight jump/split flag, forming-bar detection & exclusion option for closed-bar inference, and attach `marketDataTimestampIst` + `predictionHorizonBars` to every `TradingSignal`. | Unit tests with malformed, duplicate, zero-volume, corporate-split, and forming-bar fixtures verifying zero silent fabrication and strict alert generation. |
| 9 | **Medium** | `server/quant/strategies.ts` (L18, L348, L470–533) | **Strategy Metadata/Code Mismatch & Weak `NO_TRADE` Gating:** `orb-15-breakout` metadata states `REL_VOL >= 1.35` while switch uses `>= 1.3`; `high-conviction-ai-ensemble` uses `minProbThreshold` `0.62` symmetrically via `1 - mlProbUp`; 12 of 15 built-in strategies lose money net of NSE fees on OOS `5m`. | Misleads strategy inspection (`1.35` vs `1.3`) and routes low-expectancy setups (`opening-gap-reversal` `-₹2,08,041`, `vwap-momentum-pullback` `-₹1,23,104`) without cost-viability/expected-move filters. | Align `orb-15-breakout` (`1.35`), pass both `probUp` & `probDown` into `evaluateStrategyAtBar`, add minimum expected ATR move vs transaction-cost hurdle check, and document honest performance of all 15 strategies. | Verify strategy metadata matches execution rules and re-run 15-strategy baseline vs updated comparison. |
| 10 | **Medium** | `server/quant/indicators.ts` (L131–165) | **Wilder ATR/ADX/RSI Warmup Approximation:** For `i < 14`, `smoothTr` accumulates unnormalized sums while `atr` averages, and `adx = dx` unsmoothed at `i = 1..13`; `rsi14` uses `Math.max(1, i - 1)` denominator at `i = 1`. | Causes minor early-bar ADX/RSI distortion before bar 28 (mitigated partly by `i >= 25` warmup guard, though ADX needs 28 bars for full Wilder smoothing). | Standardize Wilder 14-period SMA seed at bar `14` + Wilder smoothing thereafter cleanly, keeping strict causality (`<= i`), and enforce `i >= 28` warmup in labeled dataset/strategies. | Causal invariance test: mutating any candle `j > t` produces bitwise identical `indicators[t]`. |
| 11 | **Low** | `server.ts`, `src/App.tsx`, `GEMINI_API_KEY` | **External Dependency Limitations:** Sandbox `GEMINI_API_KEY` returns `401`; FII/DII requires NSE vendor feed; automated Playwright UI runner absent. | Cloud Gemini synthesis & File Search cloud sync cannot execute live without a valid key (local Hybrid RAG & deterministic grounded fallback operate cleanly). | Preserve honest `UNAVAILABLE` / `DETERMINISTIC_GROUNDED_FALLBACK` notices and expose clear UI states for real `.NS` vs local research dataset separation. | Live HTTP smoke tests + `tsc --noEmit` + `vite build` + expanded `tsx --test` suite. |

## 3. Infrastructure & Security Verification
- `GEMINI_API_KEY`, `ML_SERVICE_TOKEN`, `MCP_AUTH_TOKEN`, and broker keys remain strictly server-side (`server/` & `server.ts`); never leaked in `src/` or MCP tool outputs (`sanitizeOutput` scrubs tokens).
- Live broker order placement remains structurally impossible (`liveExecutionEnabled: false` across all 4 broker adapters; no order submission endpoint exists for real brokers).
- Persistence uses atomic write-and-rename (`arthquant-state.json.tmp` -> `arthquant-state.json`).
